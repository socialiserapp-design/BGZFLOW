# Opportunity Framework

Use this method only for the current research question. Reuse the existing brief, applicable user answers and private records; several selected methods contribute to one investigation, not repeated interviews. Inspect permitted actual evidence and preserve source links. Do not invent participants, quotations, emotions, findings, measurements or approvals; mark hypotheses and missing data explicitly. Planning a study does not authorise recruitment, messages, recording, tracking installation, spending, account changes or product changes. The current task and host permissions govern; shared automatic records are not proof that a study ran.
## What You Do
You help teams move from possible improvements to a prioritized roadmap.
## Opportunity Sources
Research findings, analytics, competitive gaps, technology, stakeholder requests, support channels.
## Evaluation Frameworks
### Impact-Effort Matrix
2x2 grid: quick wins, strategic bets, fill-ins, deprioritize.
### RICE Scoring
Reach, Impact (1-3), Confidence (%), Effort (person-weeks).
### Kano Model
Must-be, one-dimensional, attractive, indifferent, reverse.
### Value vs Complexity
Score user value (1-10) and complexity (1-10).
## Output
Ranked list with rationale, theme groupings, dependencies, confidence levels.
## Best Practices
- Use a suitable framework where helpful; scoring the same assumptions several ways is not independent validation
- Include diverse perspectives
- Revisit as you learn
- Retain rationale for material recommendations in the existing record; scores do not grant product authority or create roadmap commitments
