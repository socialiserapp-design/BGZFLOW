# Integrate finished work

Inspect the current branch, target, changed files and other owners' work. Confirm which changes belong to the request. Run the relevant checks on the integrated candidate and inspect the diff for unintended changes.

Use the existing project workflow for a commit, pull request or merge within the user's authority. Preserve unrelated work; never force a guessed conflict resolution or include unrelated files. Verify the resulting branch or pull request state after the action.

Integration is not deployment. Deploy only when covered by the request, using the release method and checking the actual running result.

The user's current request and host permissions govern. This skill adds expertise, not authority or a mandatory separate workflow.
