# Stageshow, reconciled

Stageshow (`npx skills add benjitaylor/skills --skill stageshow`; Node 20.19+) builds faux product UI: stills, feature cards, cursor demos and bento grids as ordinary React components. It ships a `SKILL.md` with a seven-step workflow, fifteen references, about forty gold examples to copy from, product studies, bad/good teaching pairs, a copy-in React kit (`Stage` with a scripted `Act`, real-geometry `Window` and `Phone`, motion parts such as `Fly`, `Collapse`, `Roll`, `Count`, `Connector`, `Camera`), and scripts that film the result (`film.mjs`, `jumps.mjs`, `layout.mjs`). The craft is distilled in [MOC-faux-ui](MOC-faux-ui.md); this node compares optional implementation choices and reconciles them with the actual request.

## Who owns what when it is installed

Stageshow is a possible React illustration kit, not the automatic owner of every hero, card or demo. Inspect the existing stack and useful examples before selecting it. Keep the user's tokens, identity, content and required behavior. A non-React or static deliverable can use the existing implementation and [product-shot-framing](product-shot-framing.md) and [faux-ui-restraint](faux-ui-restraint.md).

Use available filming tools when they provide useful evidence. A kit, gold example or `--gate` does not impose a new approval stage or require announcing a tool that was not used.

## Conflicts, settled

| Topic | Adaptation for the actual work |
|---|---|
| Arrival and exit | Source storytelling arrivals around 0.8–1s are different from interactive feedback. Choose by function and actual platform; acceleration is not categorically forbidden. |
| Press and typing | The source's 0.9 cursor dip, film example 0.84 and 35ms characters are examples for different subjects. Preserve actual product feedback and sufficient reading time. |
| Autoplay | Do not introduce loops merely because the kit has them. For moving content that starts automatically, lasts over five seconds and is presented alongside other content, check WCAG 2.2.2 pause/stop/hide requirements and its essential-activity exception. Honor reduced-motion needs. |
| Screen readers | A decorative grouped illustration may use an accessible image summary and remove fake controls from tab order. A functional experience must retain meaningful controls, focus, labels and headings. |
| Placeholder content | Bars can quiet peripheral illustrative content; no fixed 3–7 string quota. Preserve the content that explains the feature, and distinguish synthetic examples from real claims. |
| Marks and studies | Check rights and genuine relationships. Studying an interaction does not permit implying endorsement or copying another brand's identity. |

Use the current brief to resolve creative choices; no source kit wins by default.

## Dependencies

The inspected source reports React 18+, react-dom and lucide-react; filming uses dev-only playwright-core and a local Chrome. Its playground also includes Vite and optional portless. Verify actual versions, compatibility, licence and existing dependencies before reuse. Install only what the authorized work needs. Existing engineering authority covers routine compatible setup; ask only about new spending, sensitive access or a material unresolved scope/product decision. Do not run a foreign setup script or cleanup step without inspecting its effects.

## Gotcha

Copying a gold example and changing only the product name is not done: it still reads as the example's product. Swap in the brief's tokens, icons, chrome and words, then verify the actual requested composition and behavior. A source example is a reference, not the acceptance authority.
