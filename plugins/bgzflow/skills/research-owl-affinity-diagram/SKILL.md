# Affinity Diagram

Use this method only for the current research question. Reuse the existing brief, applicable user answers and private records; several selected methods contribute to one investigation, not repeated interviews. Inspect permitted actual evidence and preserve source links. Do not invent participants, quotations, emotions, findings, measurements or approvals; mark hypotheses and missing data explicitly. Planning a study does not authorise recruitment, messages, recording, tracking installation, spending, account changes or product changes. The current task and host permissions govern; shared automatic records are not proof that a study ran.

Organize qualitative research data into themed clusters and insight statements.

## Instructions

1. **Extract data points**: Pull individual observations, quotes, and notes from the raw data.
2. **Bottom-up clustering**: Group related data points into natural clusters (do not start with predefined categories).
3. **Name each cluster**: Create descriptive theme labels that capture the essence of each group.
4. **Create hierarchy**: Organize clusters into higher-level themes (as many top-level themes as the actual evidence supports).
5. **Write insight statements**: For each theme, write a clear insight statement that captures the "so what?"
6. **Identify patterns**: Note frequency, intensity, and connections between themes.
7. **Prioritize**: Rank insights by impact on design decisions.
8. Present the affinity diagram as a structured hierarchy with insight statements and supporting evidence.

## Cross-Interview Sampling Principle

**Index evenly across all participants.** When working from multiple interview transcripts, inspect every relevant source in bounded sections before final synthesis, stating exclusions and coverage gaps. Do not over-represent early transcripts or the most recent input.

- Retain each participant’s contribution and context; raw quote frequency is not population prevalence
- Link retained observations to existing pseudonymous source references; do not expose identity or demand new manual IDs
- Reconcile coverage against the supplied sources. If a participant contributes no relevant observation, say so rather than inventing a quotation or theme
- Patterns that appear in only one interview should be flagged as single-source, not discarded

This prevents the common LLM failure mode of building themes from the first one or two transcripts and fitting the rest retroactively.
