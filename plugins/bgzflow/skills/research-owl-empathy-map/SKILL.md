# Empathy Map

Use this method only for the current research question. Reuse the existing brief, applicable user answers and private records; several selected methods contribute to one investigation, not repeated interviews. Inspect permitted actual evidence and preserve source links. Do not invent participants, quotations, emotions, findings, measurements or approvals; mark hypotheses and missing data explicitly. Planning a study does not authorise recruitment, messages, recording, tracking installation, spending, account changes or product changes. The current task and host permissions govern; shared automatic records are not proof that a study ran.

Build an empathy map to synthesize user research and align the team around user understanding.

## Context


## Domain Context

- Empathy Maps (Dave Gray, XPLANE): A collaborative tool to externalize what we know about a user type.
- Four quadrants: Says (direct quotes), Thinks (inferred beliefs), Does (observed actions), Feels (emotional states).
- Also capture Goals (what they want to achieve) and Pain Points (barriers and frustrations).
- Best created from actual research data, not assumptions.

## Instructions

The user will describe their user type and available research data. Work through these steps:

1. **Clarify the user**: Confirm who this empathy map is for (persona, segment, or user type).
2. **Map each quadrant**:
  - **Says**: Direct quotes and statements from research (use actual quotes where available)
  - **Thinks**: Explicitly labelled hypotheses about beliefs or concerns, distinguished from direct statements
  - **Does**: Observable actions, behaviors, and workarounds
  - **Feels**: Reported emotions with source support; inferred emotional states stay explicitly tentative
3. **Identify goals**: What is this user trying to achieve?
4. **Identify pain points**: What barriers, frustrations, or unmet needs exist?
5. **Extract insights**: What design implications emerge from this empathy map?
6. **Note gaps**: What do we still need to learn?
7. Explain the relevant rationale and evidence. Present the empathy map in a clear, visual-friendly format.
