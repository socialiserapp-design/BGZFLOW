# Report current status

Recover the agreed outcome, current task record and latest user changes. Check the actual state of relevant jobs and deliverables; do not treat an old running marker or a successful command as live proof.

Report what works, what is in progress, the meaningful unresolved issue and the next owner/action. Distinguish a completed subtask from the overall goal. A status request does not authorise unrelated fixes, new work or another review cycle.

The user's current request and host permissions govern. This skill adds expertise, not authority or a mandatory separate workflow.
