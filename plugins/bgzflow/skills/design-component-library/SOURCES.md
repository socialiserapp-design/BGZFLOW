Substantive imports are all eleven files in upstream `components/`, retained under `references/components/`: atoms, molecules, organisms, templates, advanced forms, navigation, overlays, data display, data visualisation, feedback and the icon system. This contains all 52 numbered component/template specifications plus the icon-system reference; no component-spec file was excluded. These are detailed specifications and diagrammed layouts, not prebuilt framework components. Browser algorithms from `scripts/verify_focustrap.mjs` and `verify_rtl.mjs` become `scripts/verify-focus-trap.mjs` and `verify-rtl.mjs`; `_targets.mjs` is adapted. `_browser.mjs`, platform mapping and usage guidance integrate the source with BGZFLOW.

Adaptations remove the native-select ban, compulsory eight-state counts, fixed theme/palette/size adoption and blanket mobile-first/framework generation, new rate-limit/countdown gates and obligatory type-to-confirm friction. All illustrated settings, authentication providers, table controls and layouts remain examples, not authority to add product scope. Existing/native dialog primitives are preferred over a compulsory new global modal. Examples map into existing product tokens, applicable states and platform semantics. Native grid guidance avoids adding application mode solely for complexity. The probes accept a specific authorised HTTP(S) test target or owned file, use proper file URLs, treat missing tooling/navigation as unavailable, close their isolated browser, avoid printing target URLs and do not mutate a trigger ID for focus tracking. The source observation algorithms are narrow and their limits are stated, not promoted into a full accessibility certification.

No upstream `CLAUDE.md`, `AGENTS.md`, settings, hooks, gate runner, Stop requirement, permission allow-list, installer, paid API, remote script loader or automatic record/receipt system is included. External browser dependencies are optional existing tools and are not redistributed here. No browser was launched during import; syntax and offline input checks do not establish live browser operation.
