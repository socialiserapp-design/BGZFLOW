# Existing review and verification

This historical name does not promise zero defects or impose additional release conditions.

For whole-product, feature or change diagnosis, use [full-spectrum audit](../bg-full-spectrum-audit/SKILL.md), preserving the requested scope and authority. For an authorised completion or release check, use [the existing release checker](../bg-check-it-before-release/SKILL.md) with the relevant audit evidence.

Reuse the project's meaningful behavioural tests. Do not create a mandatory JavaScript gate, impose one product's design conventions, require a fixed reviewer count, or repeat the release review merely because this entry was invoked. Follow current user decisions and report missing evidence honestly.
