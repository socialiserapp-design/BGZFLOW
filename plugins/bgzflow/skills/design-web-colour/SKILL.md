# Detailed web craft

Recover the current request, approved visual identity, supported browsers and existing implementation. Read the relevant sections of [the detailed source-adapted recipes](references/recipes.md) before implementation. They contain concrete CSS and technical checks; load only the needed section.

Share the existing brief, decisions and records with the master and other specialists. Do not restart questioning, create a separate design ledger or change user choices. Use actual rendered results, relevant fonts/content and supported languages to assess the change. A new colour scale or font declaration alone does not prove a usable screen. Report unavailable surface checks plainly.
