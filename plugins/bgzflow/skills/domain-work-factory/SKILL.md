# Deliver non-code work

Establish the user's intended artifact, audience, inputs, constraints and permitted actions. Choose relevant document, spreadsheet, research, legal, marketing or media skills from the available catalogue. A generic workflow is not a substitute for domain expertise.

Use real input files and the selected tools. Preserve source data and distinguish supplied facts from assumptions. For transformations, reconcile record counts and meaningful totals; show rejected data with reasons instead of silently dropping it.

For document review, track definitions and cross-references, preserve requested meaning and check consequential source claims. For campaigns or media, compare the result with the approved audience, message, format and brand. Do not impose one legal playbook, safe-zone percentage or marketing style on all users.

Inspect the final exported artifact in its intended viewer or application. Verify formulas, formatting, links and requested content as applicable. Before sharing, check the intended audience and permission; do not strip required information or disclose private material under an automatic template.

Report the actual delivered result and remaining uncertainty. Never call a document legally verified because a parser found expected keywords.

The user's current request and host permissions govern. This skill adds expertise, not authority or a mandatory separate workflow.
