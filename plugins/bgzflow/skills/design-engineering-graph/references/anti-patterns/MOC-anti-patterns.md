# MOC — Anti-Patterns

The frame: *could this have been generated in 30 seconds with a prompt?* If yes, fix it.

This MOC is short on purpose — most anti-patterns are subtle enough to live as one consolidated reference. When in doubt, load this one.

## Nodes

- [ai-default-tells](ai-default-tells.md) — Purple gradients, Inter, pure black dark mode, Lucide icons, lorem ipsum. The full list.
- [unslop-pass](unslop-pass.md) — The process for a screen that looks generated — squint, subtract first, sweep color → type → layout → decoration → icons → copy → motion, then put a point of view back in, then audit for survivors. Fifty median choices compound into a recognizable one.
- [content-authenticity](content-authenticity.md) — Real data, specific odd numbers, written copy, real photos. The opposite of lorem-ipsum and generated marketing tropes.
- [copy-tells](copy-tells.md) — The statistical habits that mark prose as generated — model vocabulary, "not just X but Y", the rule of three, false ranges, stacked hedges, em dashes, bold inflation, generic conclusions, chatbot residue — and the two tests every product sentence must pass.
- [code-tells](code-tells.md) — Generated UI code is rarely buggy and still costs you — narrated comments, catch theater, silent fallbacks, casts that delete compiler errors, V2 names, one-call wrappers, dead scaffolding, celebratory logs, weakened tests, drive-by diffs. Investigate actual harm before scoped cleanup; deletion is not a universal fix.
- [screenshot-critique](screenshot-critique.md) — Critique the render, never your own code — single-purpose passes over screenshots at three widths, useful findings in the existing record, a fix order where later items cannot rescue earlier ones, and task-appropriate repair and verification. Subtraction that leaves a page thin loses.

- [leftovers-and-leaks](leftovers-and-leaks.md) — What the build process leaves behind and the visitor sees — dev panels mounted for everyone, scaffolding routes indexed, debug logs of a session, secrets behind a public prefix, TODOs on the payment path. Gate what you can't prove is dead; report names, never values.
