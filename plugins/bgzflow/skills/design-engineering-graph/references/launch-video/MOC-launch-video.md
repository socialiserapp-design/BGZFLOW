# MOC — Launch video

Use the nodes needed by the requested film, existing project and approved direction. Editorial approach, story, timing and sound inform each other; this is a navigation map, not a mandatory sequence or an instruction to load every node. Keep the actual renderer unless a justified authorized change is needed.

The source reports measurements of 29 Skale pieces, 18 other films and HeyGen launch sources on 2026-09-28. Those historical observations are not independently reproduced by this import; the cited corpus/scripts are not bundled here. Distinguish them from measurements of the current output.

## What every register keeps

Preserve truthful product claims, legibility, the approved identity, appropriate rights and accessibility. Inspect unwanted flashes, accidental blank frames, unreadable type and unexplained discontinuity. A deliberate hold, fade, decorative motion, silent passage or block title is not a failure merely because it differs from the source corpus. No fixed copy count, stillness share, sound placement or transition budget applies to every film.

## Who builds it

Use the actual available rendering stack and authorized tools. HyperFrames, Remotion/cinetic and Scenario are options with different dependencies and terms, not automatic owners. Inspect helpers before running setup or delivery scripts; do not install services, spend money, overwrite work or generate extra formats just because a reference suggests it. ## Cross-cluster

- A product state change is not a film seam: [fly-not-teleport](../motion/fly-not-teleport.md) and [cross-blur-transitions](../motion/cross-blur-transitions.md) own transitions inside an interface.
- UI durations and springs ([duration-table](../motion/duration-table.md), [spring-animations](../motion/spring-animations.md)) do not transfer to a film: a 60 s film has no 300 ms ceiling (Skale's counters run 1.15 s, its dissolves 0.45 s).

## Gotcha

A numeric match to a reference corpus does not prove the film communicates this product. Load only the references that can improve the current outcome, and verify the actual deliverable rather than adopting an entire foreign workflow.
