# MOC — Faux UI

A product shot is not the product. It is an illustration of one moment in it: a window cropped to the panel where the story happens, a cursor that does one satisfying thing, a payoff that holds. Agents can build the parts; what they get wrong is the hundred small decisions around them, and the result reads as generated. This cluster writes those decisions down.

The one sentence the cluster hangs on: **it reads as a real product, simplified to what the viewer needs, framed with intent, and every motion has a cause.**

Five ways it fails, each owned by a node:

| Failure | Looks like | Owner |
|---|---|---|
| Too much | Real text in every row, numbers everywhere | [faux-ui-restraint](faux-ui-restraint.md) |
| Wireframe | Two grey blobs and a button | [faux-ui-restraint](faux-ui-restraint.md) |
| Unreadable framing | Important details lost by shrinking or clipping; even margins alone are not a flaw | [product-shot-framing](product-shot-framing.md) |
| Flat | Every object the same weight in the same bordered card | [product-shot-framing](product-shot-framing.md), [bento-grids](bento-grids.md) |
| Bland | A grey window and a cursor, whatever the brief's style was | [faux-ui-restraint](faux-ui-restraint.md) (character is real too) |
