# Source and adaptation

Substantive technical recipes adapted from [olzn/ui-craft](https://github.com/olzn/ui-craft), `surface-typography`. Revision: `e42434b0f3ad317363ad6e7b4d2b568a27cdcfa6`. MIT copyright 2026 olzn retained.

BGZFLOW preserves CSS examples and technical methods, while replacing compulsory house style, fixed counts/values, blanket font/palette bans and per-skill learning files. Existing design choices, supported content, relevant checks and private project records govern. The upstream coordinator is not installed as a competing workflow. Reference links now use existing BGZFLOW methods. Source claims about perceptual uniformity and APCA were qualified; example numbers are not guarantees.
