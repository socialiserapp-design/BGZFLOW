# Choose the research method for the actual uncertainty

These are substantive adapted Owl methods. Select the one that resolves the
current decision, through the normal Jev/fallback path. They share the same brief,
source evidence, user answers and private project records. Planning a study does
not authorise recruitment, messages, recording, new access or spending.

| Current need | Method |
| --- | --- |
| Group supplied observations into supported themes | [Affinity diagram](../../research-owl-affinity-diagram/SKILL.md) |
| Inspect actual funnel, cohort or event patterns | [Behavioural analytics](../../research-owl-behavioural-analytics/SKILL.md) |
| Analyse how participants grouped content | [Card sorting](../../research-owl-card-sort-analysis/SKILL.md) |
| Plan repeated observations over time | [Diary study](../../research-owl-diary-study-plan/SKILL.md) |
| Map what evidence says people think, feel, say and do | [Empathy map](../../research-owl-empathy-map/SKILL.md) |
| Prepare non-leading interview questions | [Interview script](../../research-owl-interview-script/SKILL.md) |
| Understand circumstances, progress and switching forces | [Jobs to be done](../../research-owl-jobs-to-be-done/SKILL.md) |
| Trace one person's evidenced journey | [Journey map](../../research-owl-journey-map/SKILL.md) |
| Reconcile qualitative accounts with quantitative patterns | [Triangulation](../../research-owl-qual-quant-triangulation/SKILL.md) |
| Organise retrievable source-backed research | [Research repository](../../research-owl-research-repository/SKILL.md) |
| Summarise a supplied interview faithfully | [Interview synthesis](../../research-owl-summarize-interview/SKILL.md) |
| Design an appropriate questionnaire and sampling plan | [Survey design](../../research-owl-survey-design/SKILL.md) |
| Plan observed task completion | [Usability study](../../research-owl-usability-test-plan/SKILL.md) |
| Develop an evidence-based user segment | [Persona](../../research-owl-user-persona/SKILL.md) |
| Compare relevant competitors using current evidence | [Competitive analysis](../../research-owl-competitive-analysis/SKILL.md) |
| Define meaningful success measures | [Metrics](../../research-owl-metrics-definition/SKILL.md) |
| Map a broader experience across channels | [Experience map](../../research-owl-experience-map/SKILL.md) |
| Organise content and navigation | [Information architecture](../../research-owl-information-architecture/SKILL.md) |
| Connect observed needs with opportunities and experiments | [Opportunity framework](../../research-owl-opportunity-framework/SKILL.md) |
| Relate user steps to frontstage/backstage service work | [Service blueprint](../../research-owl-service-blueprint/SKILL.md) |
| Plan a valid comparative experiment | [A/B test](../../research-owl-a-b-test-design/SKILL.md) |
| Plan testing with relevant access needs and technologies | [Accessibility study](../../research-owl-accessibility-test-plan/SKILL.md) |
| Test a proposed first-click/navigation choice | [Click test](../../research-owl-click-test-plan/SKILL.md) |
| Compare supplied concepts against agreed criteria | [Concept selection](../../research-owl-concept-selection/SKILL.md) |
| Inspect an interface against usability heuristics | [Heuristic evaluation](../../research-owl-heuristic-evaluation/SKILL.md) |
| Explore materially different design approaches | [Parallel concepts](../../research-owl-parallel-concepts/SKILL.md) |
| Choose the fidelity needed to test an assumption | [Prototype strategy](../../research-owl-prototype-strategy/SKILL.md) |
| Create realistic, non-leading test tasks | [Test scenarios](../../research-owl-test-scenario/SKILL.md) |

Use the user's current decision where it already settles a choice. Distinguish
observed findings, hypotheses, examples and proposed studies. Methods for creating
personas, empathy maps or interview summaries need actual source material for
claims about real people. A useful study plan does not prove the product works;
retain the relevant real-surface verification from the common workflow.
