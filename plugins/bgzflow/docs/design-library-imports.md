# Taste, AgentsORG and Owl integration

These imports add actual source assets, tools and methods. The existing design
master and normal Jev/main-agent selector remain the single selection path.

## Taste assets

[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) contributes the
complete pinned 1,617-file library, retaining its shared browser dependencies,
photos, icons, layouts, objects, effects, components and UI fragments. The offline
catalogue returns paginated metadata; a fresh-directory export preserves runtime
closure and credits. Original global design policies and developer CLIs are
retained as non-executable source reference, not loaded operational instructions.
Approved fonts, colours, content and platform behaviour govern actual adaptation.

Original code is MIT. Photographs and icons have separate per-asset terms and
source credits. See [asset notices](../skills/design-taste-assets/THIRD_PARTY_NOTICES.md)
and [the per-file rights map](../skills/design-taste-assets/asset-rights.json).
No font binary, automatic download, browser session or new service is enabled.

## AgentsORG graph and tools

[AgentsORG/design-engineering](https://github.com/AgentsORG/design-engineering)
contributes the complete pinned 201-node design reference graph, local WAV-family
and cue-sheet generators, and the SVG flipbook assembler. Nodes are reached through
ordinary relative links, so no external graph service is required. The graph is
for connected reference discovery; direct sound, SVG, motion, prototype and
research tasks retain their relevant specialist owners.

Concrete recipes remain. Operative instructions that impose a foreign house
style, automatic release/cleanup, compulsory plans/records or a fixed design count
are adapted to the shared current brief. Local sound synthesis is the default
even when a remote key exists. Existing outputs are preserved. External/paid
options need the current task's actual authority and prerequisites.

## Owl research methods

[Owl-Listener/designer-skills](https://github.com/Owl-Listener/designer-skills)
contributes all 14 methods in its design-research collection plus 14 relevant
strategy and validation methods. Each is separately discoverable; the
[research map](../skills/bg-personal-product-design/references/imported-research-map.md)
connects the uncertainty to the method. Detailed procedures and templates remain,
with source evidence distinguished from interpretations and proposed studies.
The card-sort method also includes an offline arithmetic helper that preserves
missing observations rather than turning them into zero similarity.

Planning a study does not authorise recruitment, recording, tracking, messages,
new storage, permissions or spending. Several selected methods share existing
answers, source material and private records. No fixed interview/question count,
compulsory new document or invented participant evidence is introduced.

## Verification boundaries

Source inventories, licence notices and adaptation notes live with each import.
Local executable checks inspect actual exports, generated audio/SVG and missing
card denominators; routing checks require actual selected and loaded method
bodies. Real browser playback, GPU behaviour, sound audition and human research
quality require their relevant actual surfaces and observations. Neither an
import nor a model's judgment supplies that proof.
