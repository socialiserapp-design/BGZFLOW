# BGZFLOW 2.7.8

Adaptive AI workflow: relevant skills, preserved intent, real outcome checks and optional multi-agent coordination.

This installable package contains the large skill library and local runtime dependencies. Only relevant methods are delivered to the agent. The general bg-jev skill and six specialists use the official TypeSafe connection for selection and useful on-demand judgments. Use your own Jev key (TYPESAFE_API_KEY or your protected .typesafe_key); if unavailable, the main agent continues with the catalogue and available evidence. A local preview makes no service call. See HOW-TO-USE.md for everyday use and the specialist names.

Native hook activation and capabilities differ by host. Install through the host's supported plugin system and approve its current hooks where the host requires it. Do not bypass hook trust. See docs/adaptive-foundation.md and docs/enforcement-boundaries.md for precise behaviour and limitations.

Evaluation frameworks and original project history are not runtime dependencies. The source repository contains the optional evaluation suite.
