BGZFLOW hooks on Codex for Windows: experiment result, 2026-09-29

Question: do plugin hooks fire on Codex for Windows with no .cmd, .bat or .ps1 shim?
Answer: yes. A throwaway plugin whose hooks.json used the command form shipped in hooks/hooks.json,
    node "${CLAUDE_PLUGIN_ROOT}/hooks/<script>.mjs"
was installed with the official marketplace add and plugin add commands. Its hooks ran on SessionStart,
UserPromptSubmit, PreToolUse, PostToolUse and Stop (a user-level hook also ran on SessionEnd). Each hook received
the documented JSON on stdin and exited 0.

How Codex starts a hook on Windows (from the run below, "launched by" lines):
  1. Codex replaces ${CLAUDE_PLUGIN_ROOT} (and ${PLUGIN_ROOT}) in the command text with the installed plugin folder.
     A folder name with spaces works because the shipped command quotes the path.
  2. Codex then runs the text through Windows PowerShell with -NoProfile -Command, so a plain `node "<path>"` needs no wrapper file.
  3. Node must be on PATH. The hook's working folder is the project folder, so relative script paths do not work.

Command forms tried in the run (SessionStart):
  works   node "${CLAUDE_PLUGIN_ROOT}/hooks/x.mjs"      (shipped form; also ${PLUGIN_ROOT})
  works   node "<absolute path>/hooks/x.mjs"
  works   node -e "import(...process.env.CLAUDE_PLUGIN_ROOT...)"   (environment variable read by Node)
  works   the commandWindows field, which takes over from command on Windows
  works   PowerShell-only syntax such as $env:CLAUDE_PLUGIN_ROOT (not portable, so not used)
  fails   node "%CLAUDE_PLUGIN_ROOT%\hooks\x.mjs"     (cmd-style percent signs are not expanded)
  fails   node hooks/x.mjs                              (relative to the project folder, not the plugin)

Trust: run P3 installed the same plugin without the hook-trust bypass flag and no plugin hook ran, so on Codex
a user must review and trust the plugin's hooks first (the runs that fired used the bypass flag in a throwaway home).

Setup: Codex CLI 0.159.0, Node 24, Windows 11. A throwaway Codex home (folder name with a space) with a local
marketplace and a mock model server on the loopback address; `codex exec --json`. Nothing outside the throwaway
folders was touched. Paths below are shortened to <tmp> and <home>; environment values were removed, names kept.

Runs: P4 = plugin hooks with all six events, U1 = user-level hooks that deny or block a tool call,
P3 = the same plugin without the trust bypass.
