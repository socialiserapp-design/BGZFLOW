# Substantive design library expansion

The first seven general design specialists reorganised and strengthened existing
guidance. This expansion imports substantial additional recipes, specifications,
tools and prototype code. They remain selectively loaded through the same master
and Jev catalogue rather than running a second workflow.

| Added method | Source | Concrete contribution |
| --- | --- | --- |
| design-token-build | [plugin87](https://github.com/plugin87/ux-ui-agent-skills) | Real token-to-CSS compiler and isolated token samples; alias failure and output preservation repairs. |
| design-component-library | plugin87 | Detailed anatomy, interaction/state and accessibility specifications plus optional real-browser focus and RTL probes. These are specifications, not ready-made framework widgets. |
| design-animation-review | [Emil Kowalski](https://github.com/emilkowalski/skills) | Detailed review standards, fourteen web interaction recipes and nine choreography patterns. |
| design-prototype-lab | Emil Kowalski | Actual interactive picker markup, styling, URL selection, keyboard handling and replay code. |
| design-stitch | [Google Labs Stitch](https://github.com/google-labs-code/stitch-skills) | Local design extraction procedure, five framework guides and interchange example; optional SWC convention checker and configured-service adapter. |
| design-web-typography | [olzn UI Craft](https://github.com/olzn/ui-craft) | Detailed font loading, fallback metrics, OpenType, variable font, type-scale and rendering CSS recipes. |
| design-web-colour | olzn UI Craft | Detailed OKLCH scales, gamut, semantic theme mapping and contrast recipes. |

Each method retains its own full licence and pinned source attribution. MIT
applies to plugin87, Emil and olzn imports; Apache-2.0 to Google's imports.
Local source notes identify modifications and inspected source revisions.

Imports remove compulsory fonts/palettes, variant caps, unrequested setup,
automatic prototype deletion, duplicate records, upstream hook/settings gates
and credential extraction. Concrete examples remain, with appropriate platform,
scope and evidence requirements. Existing approved design and current user choices
govern; numeric craft examples are not permission or universal acceptance rules.

The code and documents are freely licensed. Running the user's AI, connecting a
design service, installing browser tooling or acquiring fonts can have separate
requirements. No free unlimited service is promised. Stitch remote operations
need an existing authorised connection; local extraction does not. The SWC
checker requires an existing compatible package. Browser probes require existing
Playwright and a browser. Missing prerequisites remain explicit.

The later [Taste/AgentsORG/Owl integration](design-library-imports.md) brings those
actual libraries, graph, tools and research methods into the shared selection path.
OpenDesign and additional UI Craft suites remain separately inspected candidates;
their research captures do not mean those complete products are installed.
